# Astro Relic 2.0

An immersive 3D space exploration game inspired by the wonders of our solar system.

## About the Project

Astro Relic 2.0 is a space exploration game designed to let players explore planetary environments and discover the history of space missions.

## Features

- 3D space exploration
- Planetary environments, including Mars
- Historical Mars missions:
  - Mars Pathfinder
  - Spirit
  - Opportunity
  - Phoenix
  - InSight
- 3D character movement and physics
- Interactive user interface

## Technologies

- JavaScript
- HTML and CSS
- Three.js (if used in the project)
- Cannon.js or Ammo.js (if used in the project)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Akib318/astrorelic2.0.git
   ```
2. Open the project folder.
3. Follow the project-specific instructions to install dependencies and run the game.
